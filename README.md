# SmogCast

### Air Quality Analysis and Forecasting

## About the Project

SmogCast is an R-based project focused on air quality analysis and forecasting. The project aims to explore air pollution data and understand air quality patterns through data analysis and visualisation.

## Features

- Analysis of air quality data.
- Exploring pollution trends and patterns.
- Data visualisation using R.
- Air quality forecasting.

## Technologies Used

- **Language:** R
- **IDE:** RStudio

## Project Files

- `smogcast.R` – Main R script containing the project code.

## How to Run

1. Download or clone this repository.
2. Open RStudio.
3. Open the `smogcast.R` file.
4. Install the required R packages if prompted.
5. Run the script to execute the project.

## Future Improvements

The project can be further improved by adding more datasets, exploring additional forecasting techniques, and improving the visualisation of results.
